```gdscript

static func to_tile_coords(world_pos: Vector2) -> Vector2i
```

* **Benefits:** All object placement now uses centralized snapping.
* Prevents inconsistent placement and supports override logic with the `align_to_center` flag.

* Movement is **one tile per press**.
